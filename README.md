# 📈 بورس‌کالک

ردیاب معاملات بورسی — ابزار ساده و آفلاین برای ثبت و پیگیری خرید و فروش سهام در بازار بورس ایران.

---

## ویژگی‌ها

- **مدیریت چند حساب** — می‌توانید چند پرتفوی جداگانه (مثلاً حساب شخصی، حساب خانوادگی) داشته باشید
- **ثبت معاملات خرید و فروش** — با تاریخ شمسی، تعداد سهم و قیمت؛ امکان ثبت چند ردیف در یک معامله
- **محاسبه میانگین خرید** — میانگین بهای تمام‌شده را به‌صورت خودکار حساب می‌کند
- **قیمت لحظه‌ای** — با وارد کردن قیمت جاری، سود/زیان لحظه‌ای (تحقق‌نیافته) محاسبه می‌شود
- **سهام جایزه (🎁)** — ثبت سهام جایزه با بهای تمام‌شده و مشارکت در محاسبه سود
- **حق تقدم (ح)** — ثبت حق تقدم، قیمت لحظه‌ای، و ثبت فروش آن
- **نمای کلی سبد** — داشبورد جامع با جمع سرمایه در گردش، ارزش لحظه‌ای، و سود/زیان تحقق‌یافته
- **سرمایه غیرفعال** — امکان ثبت موجودی بلااستفاده برای محاسبه جمع کل دارایی
- **اتمام معامله** — علامت‌گذاری سهم به‌عنوان «فروخته‌شده» و نگه داشتن تاریخچه
- **پشتیبان‌گیری و بازیابی** — ذخیره و بارگذاری داده‌ها به‌صورت فایل JSON
- **ذخیره محلی** — داده‌ها در `localStorage` مرورگر نگه‌داری می‌شوند، نیاز به سرور یا اینترنت نیست

| لایه | فناوری |
|------|--------|
| رابط کاربری | HTML5 / CSS3 (RTL) |

## راه‌اندازی

پروژه کاملاً استاتیک است — نیاز به نصب یا build ندارد.

**روش ۱ — باز کردن مستقیم:**
```bash
open index.html
```

**روش ۲ — سرور محلی (توصیه‌شده برای جلوگیری از محدودیت‌های CORS):**
```bash
# با Python
python3 -m http.server 8000

# با Node.js
npx serve .
```
سپس در مرورگر: `http://localhost:8000`

## نحوه استفاده

1. **ایجاد حساب** — روی «＋ حساب جدید» کلیک کنید
2. **افزودن سهم** — حساب را انتخاب کنید، سپس «＋ سهام جدید» بزنید و نماد سهم را وارد کنید
3. **ثبت خرید** — در تب «خرید»، تاریخ شمسی، تعداد و قیمت را وارد کنید؛ می‌توانید چند ردیف اضافه کنید
4. **ثبت فروش** — به تب «فروش» بروید و معامله فروش را ثبت کنید
5. **قیمت لحظه‌ای** — قیمت جاری سهم را در فیلد مربوطه وارد کنید تا سود/زیان لحظه‌ای نمایش داده شود
6. **نمای کلی سبد** — روی «📊 نمای کلی سبد» کلیک کنید تا داشبورد کامل پرتفوی را ببینید
7. **پشتیبان‌گیری** — با کلیک روی «💾 پشتیبان‌گیری» داده‌ها را به فایل JSON ذخیره کنید
8. **بازیابی** — با «📂 بازیابی» یک فایل پشتیبان را بارگذاری کنید

## محاسبات

| فرمول | شرح |
|-------|-----|
| `میانگین = جمع مبلغ خرید ÷ جمع تعداد خریدشده` | میانگین بهای تمام‌شده |
| `هزینه فروش‌رفته = میانگین × تعداد فروخته‌شده` | مبنای محاسبه سود تحقق‌یافته |
| `سود تحقق‌یافته = درآمد فروش − هزینه فروش‌رفته` | سود/زیان واقعی از معاملات بسته‌شده |
| `سود لحظه‌ای = (قیمت جاری − میانگین) × مانده سهام` | سود/زیان روی سهام باقی‌مانده |
| `سود کل = تحقق‌یافته + لحظه‌ای + سهام جایزه + حق تقدم` | |

## داده‌ها و حریم خصوصی

- تمام داده‌ها **فقط در مرورگر شما** ذخیره می‌شوند (`localStorage`)
- هیچ داده‌ای به سرور ارسال نمی‌شود
- برای انتقال بین دستگاه‌ها از قابلیت پشتیبان‌گیری/بازیابی استفاده کنید
- پاک کردن داده‌های مرورگر، اطلاعات بورس‌کالک را نیز پاک می‌کند — **قبل از آن پشتیبان بگیرید**
